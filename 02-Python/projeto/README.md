# 🤾 Handball Data Engineering 

## ℹ️ Sobre

Bem-Vindos a uma leve introdução ao caminho do projeto **Handball With Data Engineering**. Este projeto que foi criado possuí o objetivo de consolidar aprendizados de **Python** e **Pandas** através de uma prática em um projeto com dados próximos a realidade, contendo valores nulos, tipos errados de dados em colunas, entre outras inconsistências.

- Para mais detalhes sobre o projeto acesse: [`handball-with-data-engineering`](./handball-with-data-engineering)

## 🐍 Python Basics

Ao decorrer do meu projeto raiz para potfólio "data_engineer_journey", realizei estudos aprodundados na **Linguagem de Programação Python**, aprendendo de forma aprodundada fundamentos, conceitos, sintaxe e aprimoramento de lógica de programação. Todo o processo foi documentado ao decorrer de todos os dias de estudo, e cada aula e conceito tendo seu espaço dentro de um arquivo em formato README `(diario_estudos.md)` e comentários no código, visando ter uma explicação leve do que foi aprendido em cada etapa do processo de estudos.

* **Pasta de Estudos:** [`python-basics`](/02-Python/estudos/python-basics/)

## 🐼 Python-To-Data

Além da linguagem de programação, tive a decisão de me aprofundar um pouco sobre como a linguagem é utilizada especificadamente para dados, como manipulação de dados, filtragem, lidar com dados nulos, estruturas de dados, com o objetivo de obter uma introdução. Para esta etapa, realizei estudos teóricos e práticos com a biblioteca **[pandas](https://pandas.pydata.org/about)** que é frequentemente utilizada na área. A biblioteca nos trás uma estrutura de dados (DataFrames), manipulação e filtragem de dados, escrita e leitura de arquivos, além de nos proporcionar uma boa base sobre como **Python** pode ser utilizado na área de dados.

- **Pasta de Estudos:** [`pandas`](/02-Python/estudos/python-to-data/pandas/)
