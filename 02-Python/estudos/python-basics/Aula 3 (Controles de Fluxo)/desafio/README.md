### Desafio - Integre no projeto anterior um fluxo de While que repita o fluxo até que o usuário insira as informações corretas

No projeto anterior desenvolvemos tratamento de erros caso houvesse bugs ou erros no software de *Calcúlo de Bônus 2024*, com try-except pensamos em possíveis bugs e criamos caminhos de forma que não ocorresse o travamento do código.

O objetivo do projeto de hoje é potencializar estes tratamentos de erros, afim de fazer com que o usuário tenha mais tentativas caso viole alguma regra do software. Para fazer isso, vamos adicionar o **While** no código e fazer com que o loop não acabe até que valor seja correto.
